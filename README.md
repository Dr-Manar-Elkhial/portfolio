# Manar Elkhial — Portfolio Website (single page)

This is the single-page version: one file, one scrolling home page, menu
links jump to sections on that same page, and each case study opens in a
pop-up with its full detail.

## What's inside
`index.html` — the entire website. No dependencies, no build step.

## Adding your own photos — no code needed
Upload a photo with the exact filename below into a `photos` folder in your
repository, and it replaces the placeholder box automatically:

| Where it appears                          | Exact filename                     |
|--------------------------------------------|-------------------------------------|
| Ancient Egyptian Papyrus                    | `photos/papyrus.jpg`                |
| Islamic Parchment                           | `photos/parchment.jpg`              |
| Jewish Paper Manuscripts                    | `photos/paper.jpg`                  |
| Archaeological Wood & Polychrome Objects    | `photos/polychrome-coffin.jpg`      |
| Modified-Atmosphere & IPM System            | `photos/atmosphere-system.jpg`      |
| Tutankhamun Galleries                       | `photos/tutankhamun-gallery.jpg`    |
| Curriculum Design & Training                | `photos/teaching-training.jpg`      |

**How:** in your repo, open (or create) a `photos` folder → Add file →
Upload files → drag your renamed photo in → Commit changes.

## Editing text yourself
Open `index.html` on GitHub → click the pencil icon (top right) → edit
directly → Commit changes. Site updates within about a minute.

## Cleaning up the repository (removing the multi-page files)
If your repository still has the multi-page files in it (about.html,
journey.html, practice.html, research.html, teaching.html, contact.html,
style.css, script.js, and a `practice` folder), delete them so only
`index.html` (and optionally `photos/` and this README) remain. Steps:
1. Open the repository on github.com.
2. Click into each file you want gone → the trash-can icon (top right of
   the file view) → Commit changes.
3. For the `practice` folder, delete each file inside it the same way —
   once it's empty, the folder disappears on its own.
